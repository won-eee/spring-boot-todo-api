# 🚀 Spring Boot JPA & H2 Base Architecture

Spring Boot와 Spring Data JPA, H2 In-Memory DB를 활용한 백엔드 기본 아키텍처 구축 및 학습용 프로젝트입니다.

---

## 🛠️ 기술 스택 (Tech Stack)
- **Framework:** Spring Boot 3.2.4
- **ORM / Database:** Spring Data JPA (Hibernate), H2 Database
- **Build Tool:** Gradle
- **Language:** Java 17

---

## ✨ 핵심 구현 내용
- `Member` 및 `Todo` 기초 도메인 엔티티 설계
- `CommandLineRunner`를 활용한 애플리케이션 시작 시 데이터 초기화 구현
- Spring Data JPA Repository 기반의 기본 CRUD 환경 구성
- H2 In-Memory DB 연동 및 인텔리제이 개발 환경 구축
- Git / GitHub 버전을 통한 코드 관리 파이프라인 형성
